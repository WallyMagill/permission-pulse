# Core Loop Implementation Plan

**Goal:** Snapshot history records itself on Walter's Mac: scheduled scans, change-driven snapshots with per-domain coverage, and diffs that only compare complete evidence.
**Spec:** `docs/superpowers/specs/2026-10-10-core-loop-design.md` — read both.
**Architecture:** Scanners decide what an item is; `SnapshotStore` persists items plus per-domain coverage and offers pure array-level diffs; `SnapshotCoordinator` decides when to write and which domains to compare; a new `ScanScheduler` decides when to scan. UI reads `SnapshotDiffs.uncomparedDomains` and `AppViewModel.latestSnapshotDate`.

## Global constraints
- Swift 6.3, MainActor-by-default; `nonisolated` only where a type must run off main.
- Swift Testing for all new tests; ~one test per stated behavior.
- Every user-facing string through `String(localized:)`.
- Read-only filesystem rule: only `~/Library/Application Support/com.wallymagill.permissionpulse/` is written.
- Files ≤ 800 lines, functions < 50 lines; no comments that restate code.
- Migration name `v6`, `schema_version` = 6.
- Package tests: `swift test --package-path Packages/<Pkg>`. App tests: `PERMISSION_PULSE_TEST_MODE=1 xcodebuild test -project PermissionPulse/PermissionPulse.xcodeproj -scheme PermissionPulse -destination 'platform=macOS,arch=arm64' -only-testing:PermissionPulseTests CODE_SIGNING_ALLOWED=NO`. If a package fails with a module-cache-path error, `rm -rf Packages/<Pkg>/.build` (gitignored) and rerun.

### Task 1: Label-less plists are inert

**Outcome:** A well-formed plist dictionary without a `Label` key is neither listed nor counted as omitted; unreadable/non-dict/non-string-Label files still count as omitted.

**Files:** modify `LaunchAgentScannerFS.swift` (`decodePlist` returns a 3-way result: `.item(LaunchAgentItem)`, `.inert`, `.omitted`; `scanDirectory` counts only `.omitted`); tests in `LaunchAgentScannerFSTests.swift`.

**Decisions:** Detect inert by `PropertyListSerialization.propertyList(from:)` → `[String: Any]` with `dict["Label"] == nil`. Log inert files at `.debug` with filename.

**Acceptance:** new test "empty-dictionary plist is inert: no item, no warning" fails before, passes after; existing malformed-plist test still passes. `swift test --package-path Packages/PermissionsScanners`.

- [ ] Done and committed

### Task 2: Coverage on snapshots (schema v6)

**Outcome:** Every snapshot row carries per-domain coverage; failed domains store no rows; v5 databases migrate with `complete`.

**Files:** create `SnapshotCoverage.swift`; modify `SnapshotStore.swift` (migration `v6`, write path, coverage read); modify `AGENTS.md` fragile-surfaces row "Snapshot store schema v5" → v6 (coverage columns); tests in new `SnapshotCoverageTests.swift`.

**Interfaces — produces:**
```swift
public enum SnapshotCoverage: String, Sendable, Equatable { case complete, degraded, failed }
public struct SnapshotDomainCoverage: Sendable, Equatable {
    public var tcc: SnapshotCoverage
    public var btm: SnapshotCoverage
    public var launchAgents: SnapshotCoverage
    public static let allComplete: SnapshotDomainCoverage
}
// SnapshotStore
public func writeSnapshot(grants: [PermissionGrant], launchAgents: [LaunchAgentItem],
                          btmItems: [BTMItem], coverage: SnapshotDomainCoverage,
                          at date: Date) async throws -> SnapshotID
public func coverage(snapshotID: SnapshotID) async throws -> SnapshotDomainCoverage
public func snapshotDate(snapshotID: SnapshotID) async throws -> Date?
```
`writeFullSnapshot(grants:launchAgents:btmItems:at:)` stays and forwards with `.allComplete`.

**Decisions:** Columns `tcc_coverage`, `btm_coverage`, `launch_agent_coverage` TEXT NOT NULL DEFAULT 'complete'. A `failed` domain's items are ignored on write even if non-empty. An unknown stored string decodes to `.failed` and logs (`Logger` category `snapshot-store`).

**Acceptance:** tests — v5→v6 fixture (reuse `SnapshotV4Fixture` pattern) keeps rows and reports `.allComplete`; coverage round-trips; failed domain writes zero child rows; `schemaVersion() == 6`. `swift test --package-path Packages/PermissionsStore`.

- [ ] Done and committed

### Task 3: Array-level diffs and `evidenceChanged`

**Outcome:** The store can tell whether a fresh scan differs from a stored snapshot using exactly the diff rules Recent Changes uses.

**Files:** create `SnapshotStore+Diff.swift` (move `diffLaunchAgents/diffTCCGrants/diffBTMItems` here; `computeDiff` and identity/equivalence helpers become `static` internal in the extension); tests in new `EvidenceChangedTests.swift`.

**Interfaces — produces:**
```swift
public static func diffTCCGrants(before: [PermissionGrant], after: [PermissionGrant]) -> TCCGrantsDiff
public static func diffBTMItems(before: [BTMItem], after: [BTMItem]) -> BTMItemsDiff
public static func diffLaunchAgents(before: [LaunchAgentItem], after: [LaunchAgentItem],
                                    compareDisabled: Bool) -> LaunchAgentsDiff
public func evidenceChanged(since snapshotID: SnapshotID, grants: [PermissionGrant],
                            launchAgents: [LaunchAgentItem], btmItems: [BTMItem],
                            coverage: SnapshotDomainCoverage) async throws -> Bool
```

**Decisions:** `evidenceChanged` = coverage differs OR, for each domain not `.failed` in `coverage`, the array diff vs the stored rows `hasContent`. Launch-agent `compareDisabled` = the stored snapshot's `launch_agent_disabled_captured`.

**Acceptance:** tests — identical evidence → false; one added grant → true; coverage flip only → true; changed items in a `.failed` domain → false. Existing `TCCDiffTests`/`BTMDiffTests`/`LaunchAgentsDiffTests` unchanged and green.

- [ ] Done and committed

### Task 4: Retention keeps the baseline

**Outcome:** `pruneSnapshots(olderThan:)` never deletes the newest snapshot at or before the cutoff nor the overall latest.

**Files:** modify `SnapshotStore.swift` (`pruneSnapshots`); tests in `SnapshotRetentionTests.swift`.

**Decisions:** SQL: delete `WHERE created_at < ? AND id NOT IN (<baseline id>, <latest id>)` with ids resolved via `latestSnapshotID(atOrBefore:)` / `latestSnapshotID()` semantics inside the same write transaction.

**Acceptance:** new tests — only snapshot is 100 days old with 90-day retention → kept; three old + one new → newest-old and new kept, others deleted. Existing retention tests updated only where they asserted deletion of what is now the baseline (state which in the commit message).

- [ ] Done and committed

### Task 5: Coordinator writes on change and gates diffs per domain

**Outcome:** Degraded/failed domains no longer block snapshots; unchanged scans write nothing; changed scans write the same day; window diffs skip domains not complete at both ends and report them.

**Files:** create `Packages/PermissionsUI/Sources/PermissionsUI/HistoryDomain.swift`; modify `SnapshotDiffs.swift` (add `uncomparedDomains: [HistoryDomain]`, init param default `[]`), `AppViewModel.swift` (`public var latestSnapshotDate: Date?`), `PermissionPulse/PermissionPulse/SnapshotCoordinator.swift`; tests in `SnapshotCoordinatorTests.swift`.

**Interfaces — produces:**
```swift
public enum HistoryDomain: String, Sendable, CaseIterable { case tcc, btm, launchAgents
    public var displayName: String } // "Permissions", "Background Items", "Launch Agents"
```

**Decisions:**
- Coverage mapping from `ScanAvailability`: `.complete` → complete, `.degraded` → degraded, `.failed`/`.never` → failed.
- Remove `scanFullySucceeded()` and the same-day gate. Write when `latestSnapshotID() == nil` or `evidenceChanged(...)`. Still persist `lastSnapshotDate` after a write.
- Diff gating per domain via `coverage(snapshotID:)` of both endpoints; non-complete → empty domain diff + entry in `uncomparedDomains`.
- After refresh, set `viewModel.latestSnapshotDate` from `snapshotDate(snapshotID:)`.
- `ResetAllDataService` clears `latestSnapshotDate` alongside the diffs.

**Acceptance:** tests — degraded launch agents still writes; second identical scan writes nothing; changed scan same day writes a second snapshot and the Yesterday diff shows it; degraded endpoint lists `.launchAgents` in `uncomparedDomains` with empty LA diff. Existing coordinator tests that asserted "skip when degraded" are rewritten to the new rule (named in commit). App test command green.

- [ ] Done and committed

### Task 7: Scan scheduler

**Outcome:** Scans run on wake, on calendar-day change, and when the dropdown or detail window appears with a last scan older than 15 minutes; each scan logs its duration.

**Files:** create `PermissionPulse/PermissionPulse/ScanScheduler.swift`; modify `MenuBarContentView.swift` and `DetailWindowView.swift` (`onBecameVisible: (() -> Void)?` init param, called in `.onAppear`), `PermissionPulseApp.swift` (own and start the scheduler after launch scan; pass `onBecameVisible`), `ScanCoordinator.swift` (log `runScan` duration at `.info` via `ContinuousClock`); docs `docs/03-architecture.md` scan-trigger paragraph; tests in new `ScanSchedulerTests.swift` (app target).

**Interfaces — produces:**
```swift
@MainActor final class ScanScheduler {
    static let staleScanInterval: Duration = .seconds(15 * 60) // guess; retune from duration logs
    init(workspaceCenter: NotificationCenter, defaultCenter: NotificationCenter,
         now: @escaping () -> Date, lastScanDate: @escaping () -> Date?,
         requestScan: @escaping () -> Void)
    func start()
    func noteBecameVisible()
}
```

**Decisions:** Observers use `NSWorkspace.didWakeNotification` and `.NSCalendarDayChanged`; `requestScan` calls `Task { await appDelegate.rescan() }` — coalescing stays in `performRescanIfIdle`. Scheduler is not started in test mode.

**Acceptance:** tests with private `NotificationCenter` instances — wake posts → 1 request; day change → 1; `noteBecameVisible` with last scan 20 min ago → 1, 5 min ago → 0, nil → 1. App test command green.
