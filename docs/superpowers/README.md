# Internal planning notes

The files under `docs/superpowers/` are internal planning notes, design specs, implementation plans, and agent prompts written during development. They are not user documentation and may describe code that has since changed; the numbered docs in `docs/` and the top-level `README.md` describe the app as it is. The `agent-access` spec and plan (`specs/2026-07-15-agent-access-foundation-design.md`, `plans/2026-07-15-agent-access-foundation.md`) describe an unreleased experiment that is not part of any release.
